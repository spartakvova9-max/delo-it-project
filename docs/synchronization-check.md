# Контроль независимого клона

Этот файл создан в отдельной рабочей копии после git clone публичного репозитория.
Коммит отправляется в lifecycle/06-deployment. Основная копия сначала выполняет
fetch и проверяет, что HEAD не изменился; затем pull --ff-only получает изменение.
Файл сохраняется как проверяемый результат обмена, а не только описание команд.
Дополнительных участников для этой демонстрации не требуется.
