# Решения интерфейса

Реестр показывает номер, тему, вид, корреспондента, состояние, исполнителя и срок.
Контрольная дата задаётся явно; при старте выбрано 18.11.2026.
Сводка относится к текущему отбору. Карточка открывается в отдельном диалоге;
в ней показана версия и хронология событий. Просрочка подписана текстом.
Неверный период очищает старый список, чтобы его нельзя было принять за новый отчёт.
Пользовательский ввод выводится как текст, а не HTML.
