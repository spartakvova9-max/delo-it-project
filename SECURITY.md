# Ограничения безопасности учебного прототипа

Приложение предназначено только для вымышленных данных.
Выбор пользователя через X-Demo-User — демонстрация ролевых правил,
а не аутентификация: посетитель может выбрать любую учебную роль.
Проверки в сервисе предотвращают недопустимые действия выбранной роли,
но не доказывают личность посетителя.

Не загружайте настоящие персональные, финансовые или служебные документы.
Вложения и пароли здесь не хранятся. GitHub-репозиторий публичный.
Не публикуйте токены, .env, БД, приватные ключи и реальные контакты,
в том числе в коммитах, сообщениях, скриншотах и журнале CI.

Предусмотрены: SQL-параметры, ограниченные поля записи, атомарные операции,
контроль version, внешние ключи, предел JSON 64 КиБ, проверка Origin для записи,
безопасное текстовое отображение и экранирование формул CSV.
Эти меры не превращают прототип в промышленную систему.

Для внедрения потребуются: настоящая аутентификация и сессии, CSRF-защита,
TLS на доверенном прокси, разграничение доступа к отдельным документам,
резервное копирование и восстановление, неизменяемый внешний аудит,
управление секретами, проверка вложений, нагрузочные испытания,
персональные настройки часовых поясов и соблюдение применимого законодательства.
SQLite-журнал в этой работе не защищён от администратора самой базы.

Об обнаруженном дефекте не публикуйте реальные данные и секреты.
Для учебного воспроизведения достаточно описания шагов с вымышленными значениями.
